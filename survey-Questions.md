I recommend using a **100-point survey** divided into six sections.

# Team Formation Strategy

After scoring, create balanced teams instead of grouping students by similar skills.

| Role                           | Suggested Profile                                                      |
| ------------------------------ | ---------------------------------------------------------------------- |
| Solution Architect             | Highest overall score; strong communication and architecture knowledge |
| Cloud/Infrastructure Architect | Strong cloud, networking, and infrastructure skills                    |
| Security Architect             | High security, identity, and compliance knowledge                      |
| AI/Data Architect              | Strong AI, data engineering, and analytics skills                      |
| DevOps Architect               | Strong CI/CD, automation, containers, and Infrastructure as Code       |
| Business Analyst               | Strong communication, documentation, and requirements analysis         |

Each team should include a mix of experience levels (e.g., one senior, several intermediate, and one beginner) to encourage peer learning. Team assignments can also consider project preferences, but they should prioritize balanced technical coverage so every group has the capability to complete the architecture, implementation, and presentation phases successfully.
